## The picture

One steaming bowl of tonkotsu ramen, built to make you hungry at a glance:
glossy golden broth with chili-oil droplets, wavy fresh noodles lifted by
chopsticks, a halved soft egg with a jammy orange yolk, pink chashu slices,
spring onions, sesame, menma bamboo shoots and a sheet of nori, all on a
warm wooden table with steam rising and soft light from above.

## How it works

`main.py` (Python 3.13, standard library only) copies the rendered picture
`entry.png` (1024×1024 PNG) to `/output/entry.png`. The run is fully
deterministic, needs no network, and finishes in well under a second.

```sh
python3 main.py
# writes /output/entry.png (or $MAKEFUN_OUTPUT_DIR/entry.png)
```
